# MIDISC patcher

Browser patcher that builds **1.40MIDISC8.1** for Elektron Octatrack from your own stock **OS 1.40C**.

Live page: https://bkkbrls-del.github.io/midisc-patcher/

No firmware is hosted here. Patching runs entirely in the browser.
Frozen from local build 1.40MIDISC8.1 (splash 1.40MDIS81).
MIDISC8 scenes; CC filter on hold.

## Local

Open index.html via any static server (GitHub Pages, or 
px serve .).

## Flash

1. Build 1.40MIDISC8.1.bin on the page
2. Copy it to the CompactFlash **root**
3. On the unit: **OS UPGRADE** (splash shows 1.40MDIS81)
4. Keep stock 1.40C for recovery

Do not redistribute generated .bin / .syx files.
